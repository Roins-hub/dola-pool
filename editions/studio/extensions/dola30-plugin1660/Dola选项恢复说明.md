# Dola模型选项恢复（v1.6.34）

用户截图中模型菜单只剩2.0 Fast与1.0。本次恢复的是原插件包使用过的seedance_v2.5，保留这两个现有选项，不增加国内专用型号。

## 修改路径

| 层级 | 本版行为 |
| --- | --- |
| 原生配置 | 在既有Dola视频模型控制的option_list/options中补回2.5；网页据此生成菜单 |
| 客户端模型描述 | 仅缺失时使用用户原插件包中旧Dola描述；标明来源与未验证状态 |
| 输入状态 | 写video-model原生值与submitKey=model的提交记录，失败会撤销偏好 |
| 参数构建 | 原生video-creation节点重建参数后，保持所选model与resolution |
| 签名前消息 | 处理原生视频草稿及Dola旧input_skill.variables，对象/JSON表示保留 |
| 实际传输 | 观察网页正常发出的请求，不修改已签名正文，不伪造响应，不重复发送 |
| 结果判定 | 仍依据平台真实任务/视频或原始拒绝，不用菜单或文案冒充受理 |

共享适配器原来仅安装于国内，且菜单识别不接受Dreamina前缀，现已补齐Dola加载和识别。2.5、2.0 Fast、1.0之间切换会同步参数，不会在切回1.0后继续偷偷提交2.5。国内标准版/Mini偏好在Dola不生效。

恢复项不写subscription_tag=none等权益字段，原有选项与服务器错误保留。客户端描述来自原插件包，不冒充本次服务器返回的能力；modelSelection.backendVerification始终UNVERIFIED。

## 验证

233项离线回归通过，其中本轮新增9项，覆盖配置恢复、唯一ID及默认项、状态与菜单、节点参数、旧变量编码、切回1.0和原始错误透传。测试中的请求发送与签名是离线夹具，用于检查调用次数和签名先后顺序，不是真实平台生成。

本次尝试访问Dola创作页，浏览器被实际重定向到security/region-restricted，无法验证当前服务器是否重新接受2.5。交付的是原生前端配置和参数提交链路修复，尚不能宣称模型服务已恢复。

更新扩展后刷新页面，选择2.5。实际请求应观察到model=seedance_v2.5；如果平台返回模型不可用、额度或权限错误，保留该原始结果继续定位。
