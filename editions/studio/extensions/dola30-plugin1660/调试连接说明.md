# 1.6.37 调试连接修复

某个账号的本地 Service Worker 缓存已确认残留旧后台：没有 DEBUGGER_STATUS /
DEBUGGER_REPORT 消息处理，而页面面板和 manifest 已是 1.6.36。
1.6.37 使用新的后台入口 service-worker-v1.6.37.js，让浏览器注册新版后台；
不删除 Cookie、账号、缓存目录或历史数据。未改动生成参数和提示词。
更新需关闭此账号浏览器后重新打开，或在扩展管理页重新加载后刷新网页。

Chrome for Testing 支持此扩展的 Debugger 网络调试。面板出现
`The message port closed before a response was received` 表示后台消息没有返回，
不能据此认定视频参数注入成功或失败，也不能直接判定浏览器不支持调试。

更新后：

1. 在出现问题的账号浏览器打开 `chrome://extensions`，重新加载“苏生阁AI · 30秒无水印助手”，确认版本 1.6.37。
2. 保存未发送的草稿，再刷新 Dola / 豆包页面。只刷新网页不一定能更新已运行的扩展后台。
3. Dola 默认不自动开启网络调试，点击面板的“启用”。成功后按钮变为“停止”。
4. 消息通道失败时按钮显示“重连后台”，重连只读取状态，不自动启停采集。
5. 后台不可达时仍能“导出调试”，此文件明确标记为仅本地诊断，不含后台网络记录。

调试只记录启用后观察到的请求，不能补回之前生成时的提交数据。无需为了检查连接而再次生成视频。
本次验证使用临时空白浏览器 Profile 和离线网页，未访问真实账号或提交生成任务。
